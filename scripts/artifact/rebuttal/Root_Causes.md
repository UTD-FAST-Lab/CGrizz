One row per successfully reasoned boundary (root cause confirmed by the reproducing test case, the
instrumentation oracle, and the annotated-tool execution trace): 38 WALA, 44 OPAL, 69 Soot.
Each row gives the missed call edge and a short summary of the tool limitation that explains it.
